# D03 external generative runner contract v2

The v1 manifest/record schema and `generate()` path remain available for existing callers. The v2 path is selected by `tiny-fleet.drift-generative-manifest/v2` and uses `generate_v2()`; it writes `tiny-fleet.drift-generative/v2` records only after complete matrix validation.

Each v2 manifest binds the frozen sample-manifest SHA256 and all three repositories' immutable old/new commits, the base model ID and 40-hex revision, prompt-template text and SHA256, scorer ID/revision/content digest, decoding settings, seeds, repetitions, and six prompt rows. Each prompt row binds its source commit/path/file SHA256, excerpt and excerpt SHA256, and a LoRA path plus 64-hex tree digest. The adapter tree digest is SHA256 over sorted files, feeding each relative POSIX path, a NUL byte, and the raw SHA256 bytes of that file into one accumulator. The runner requires exactly three repository pairs and all six snapshot rows.

Per-record provenance includes `(repo, snapshot, arm, prompt_id, seed, repetition)`, source commit/path/excerpt hash, exact effective input and its SHA256, a derived deterministic seed, base model ID/revision, adapter digest, scorer ID/revision/digest, backend, runtime, latency, and raw output or a typed inference error. `adapter_digest` must be `null` for base and prompt-only and must match the snapshot adapter for LoRA. The validator recomputes effective inputs, hashes, and seeds and refuses duplicates, missing rows, extra rows, changed provenance, or fake backends.

`TransformersBackend` loads only from the local Transformers cache at the immutable base-model revision. It uses the local tokenizer chat template when available, fixed generation settings, a per-record deterministic seed, and an optional PEFT adapter whose directory digest is checked before loading. Device defaults to CPU. The v2 CLI uses this backend unless `--fake` is explicitly supplied; that fixture path fails before creating output and exists only to verify refusal behavior. No fake v2 record can be emitted.

The current external registration remains blocked before the experimental matrix. It does not yet contain the six source excerpts, six trained snapshot-specific adapters, or a committed deterministic scorer implementation/digest. A real base-model smoke call verified the pinned Transformers backend, but its output was not stored as an experiment record and no scorer or comparison was run. See the current state in `runs/drift-generative-v2/decision.md` and the implementation receipt after landing.
